# 第 27 章：企业 Agent 的质量闭环

本图是一份教学流程设计，帮助串起业务合同、离线评测、发布门禁与生产样本治理，不代表真实系统已经上线或通过验收。

- [交互 HTML](./eval-quality-workflow.html)：在浏览器打开，支持主题、缩放、节点搜索及导出；GitHub 文件页需要先下载。
- [双主题 SVG](./eval-quality-workflow.svg)：用于正文或 README 预览。
- [Archify 源规范](./eval-quality-workflow.json)：保留拓扑和中文说明。

主线依次回答：怎样定义成功 → 怎样隔离执行并评分 → 怎样比较与决定发布 → 怎样通过灰度发现真实问题。阻断条件包含硬违规、用例遗漏、评分错误和证据缺失；人工复核不能替代缺失的事实证据。生产反馈核实、脱敏和标注后，才能进入下一版回归集，同时保留独立测试集。

评分需要查询可信业务状态及运行轨迹。Agent 的成功声明只是一项被检查的输出，不能充当完成证据。
